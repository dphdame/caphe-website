## Structure

- **Framework:** Node 18 + Express (`src/backend/server.js`). Static HTML site; **no server-side templating engine.** Each page is a standalone `.html` file under `public/`.
- **Tutorials:** 37 Methods Lab tutorials, each `public/methods-lab/<slug>/index.html`, with a per-slug `assets/` subdir holding its PNG(s). Plus `public/methods-lab/index.html` (the hub).
- **Routing:** clean URLs (`.html` → extensionless 301); tutorials served at `/methods-lab/<slug>` (no trailing slash) from the dir's `index.html`. Static roots also mounted at `/src`, `/assets`, `/data`.
- **Deploy:** Heroku `web: node src/backend/server.js`. `predeploy` runs `npm run seo:validate` (`scripts/validate-seo.js`). Sitemap regenerated by `scripts/generate-sitemap.js`. **Manual `git push origin master` deploys to Heroku** (origin = Heroku remote; github = GitHub).
- **Tests:** **NONE.** `npm test` → `echo 'No tests configured'`. TDD requires standing up a runner (propose `node:test`, zero-dep, Node 18 built-in).

## Patterns to follow

- **No templating** → site-wide edits are per-file transforms. Write idempotent Node/Python scripts that operate over `public/methods-lab/*/index.html`; this is the "template" the PRD means.
- **Schema** = one `<script type="application/ld+json">` block in `<head>`. Tutorials already have `Article`/`LearningResource`; **append** a second `FAQPage` block (or merge `@graph`) rather than rewrite.
- **Canonical/www** is enforced by `validate-seo.js` — every indexable page needs a www canonical.
- **Image fix** = rewrite `src="assets/X"` → `src="/methods-lab/<slug>/assets/X"` (root-relative), preserving existing `alt`. Add `width`/`height` where derivable.

## Risks & considerations

- **Don't regress the schema already in place** — append FAQPage, don't overwrite Article block.
- **`validate-seo.js` coupling** — noindexing /login requires adding it to `NOINDEX_PAGES` in BOTH `validate-seo.js` and `generate-sitemap.js` or the predeploy gate fails.
- **Sitemap transition** — keep `sitemap.xml` working (PRD: old → redirect/keep) so GSC discovery isn't broken; robots.txt currently points at `sitemap.xml`; point it at `sitemap-index.xml`.
- **Bing WMT / IndexNow / GSC Request-Indexing** are external/manual actions (third-party effects) — script the IndexNow pusher (deterministic) but the dashboard logins and submissions are out-of-band, flagged for the user.
- **Content accuracy** — citations must be real (Hernán-Robins, Cunningham Mixtape, Angrist-Pischke, etc. are free/verifiable). Citation-integrity rule applies: verify URLs before baking.
- **PRD over-counts work** — schema-migration, tutorial descriptions, and tutorial contrast are already done; plan should reflect actual remaining scope, not the stale audit.
